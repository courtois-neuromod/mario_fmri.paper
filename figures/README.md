# Figures

The manuscript figures are generated by the
[`mario_fmri`](https://github.com/courtois-neuromod/mario_fmri) analysis package, which writes
each one as both PDF and PNG under `{FIG_PATH}/paper/` (default `reports/figures/paper/`):

```bash
# from a mario_fmri checkout next to this repo
for fig in fig1 fig2 fig3; do invoke paper.$fig --output-dir ../mario_fmri.paper/figures; done
```

or copy them here from `{FIG_PATH}/paper/`, keeping the file names:

| File | Used by |
|---|---|
| `fig1_datasets_overview.{pdf,png}` | Figure 1 |
| `fig2_signal_quality.{pdf,png}` | Figure 2 |
| `fig3_validation.{pdf,png}` | Figure 3 |

The LaTeX manuscript (`main.tex`) includes the PDFs; the MyST book (`paper/*.md`) includes the
PNGs. A missing PDF renders as a red placeholder box, so `main.tex` still compiles without them.
